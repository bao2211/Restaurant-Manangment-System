# Backend Documentation

This folder contains all documentation related to the RMS API Server backend.

## 📚 Documentation Files

### API & Testing
- **API_Documentation.md** - Complete API endpoints reference
- **POSTMAN_TESTING_GUIDE.md** - Guide for testing API with Postman

### CORS Configuration
- **CORS_FIX_DOCUMENTATION.md** - CORS troubleshooting and fixes
- **CORS_Configuration.cs** & **CORS_Startup_Configuration.cs** - Configuration files (moved to RMS-APIServer/)

### Deployment
- **DOCKER_DEPLOYMENT.md** - Docker deployment instructions
- **DOCKER_CORS_DEPLOYMENT.md** - Docker deployment with CORS fixes
- **DOCKER_UPLOAD_INSTRUCTIONS.md** - Instructions for uploading to Docker Hub
- **PRODUCTION_DEPLOYMENT_READY.md** - Production readiness checklist
- **DEPLOYMENT_GUIDE.md** - General deployment guide
- **DEPLOYMENT_SUCCESS.md** - Deployment verification steps

## 🔗 Related Folders

- **../scripts/** - Deployment and utility scripts (.ps1, .sh)
- **../tests/** - Test files (HTML, Postman collections)
- **../databaseSQL/** - Database scripts and migrations

## 🚀 Quick Start

1. Review API_Documentation.md for available endpoints
2. Check DOCKER_DEPLOYMENT.md for deployment setup
3. Use POSTMAN_TESTING_GUIDE.md for testing
4. See CORS_FIX_DOCUMENTATION.md if encountering CORS issues
